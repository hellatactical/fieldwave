# Made with AI

Fieldwave was made with AI assistance using ChatGPT and Codex. AI generated substantial parts of the bot, control panel, branding, documentation, tests and deployment configuration under human direction.

That describes how the project was built. Running Fieldwave does not require an AI subscription, an OpenAI API key, or an AI model. Music recommendations come from the playback extractor's related-track support.

The included automated checks exercise simulated playback and the HTTP panel. They do not establish that every music source works or replace testing on a real Discord server. This project is not affiliated with or endorsed by Discord, Unraid or OpenAI.
